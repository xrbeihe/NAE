# IP 世界观制作指南

> 面向"基于既有作品（如火影忍者、哈利波特、西游记）制作世界观"的作者。核心机制：`world_facts.json` 权威设定块，控制 LLM 对预训练记忆的使用。

## 关键认知

**LLM 预训练中已有大量主流作品内容**——你不需要教它"火影是什么"，但需要**控制它知道到什么程度、什么不能出现**。平台通过 `world_facts.json` 每轮注入权威设定实现这一点。

## world_facts.json 结构

```json
{
  "knowledge_mode": "hybrid",
  "must_follow": ["故事基于作品《火影忍者》展开", "时间线在第四次忍界大战之前"],
  "forbidden": ["不得出现佩恩/晓组织入侵木叶", "不得让佐助提前叛逃"],
  "characters": [
    {"name": "漩涡鸣人", "desc": "九尾人柱力，木叶下忍，梦想成为火影"},
    {"name": "宇智波佐助", "desc": "写轮眼拥有者，复仇者"}
  ]
}
```

### knowledge_mode 三档

| 模式 | 说明 | 适用 |
|------|------|------|
| `pack_only` | 只依据包内设定，禁用预训练知识 | 严格控制、防剧透 |
| `hybrid` | 包内设定为最高权威，未提及细节结合常识补全 | **推荐**（多数 IP） |
| `full_ip` | 基于原作自由发挥，依赖 LLM 记忆 | 高度还原原作细节 |

### 每轮注入的 prompt 块

```
【本世界权威设定】
- 知识使用模式（hybrid）：以本文件与世界观包中的设定为最高权威；…
- 冲突裁定：当本文件与任何其他来源（含预训练记忆）冲突时，一律以本文件为准。
- 必须遵守：故事基于作品《火影忍者》的世界观展开
- 禁止出现：不得让佐助提前叛逃
- 关键角色设定：
  · 漩涡鸣人：九尾人柱力，木叶下忍，梦想成为火影
```

**冲突裁定是核心**——它让包内设定压过 LLM 的预训练记忆，解决"不可控剧透/跨轮漂移/版本冲突"三大问题。

## 制作流程

### 方式 A：一键生成（推荐起点）

1. 设计器 → ✨ 一键生成 → 勾选「基于既有作品」+ 填作品名
2. 生成包自动带 `world_facts.json` 骨架（hybrid + "基于作品《X》"must_follow）
3. 上传安装 → 📖 设定编辑器填充 must_follow/forbidden/characters

### 方式 B：手写包

在包目录添加 `world_facts.json`（结构如上），改完点重载。

### 必填建议

- **must_follow**：作品名 + 时间线锚点 + 核心力量体系规则
- **forbidden**：当前时间线不应出现的主线剧情/角色结局/跨作品力量
- **characters**：玩家会频繁互动的关键角色（名 + 一句核心设定）

## 实战经验（火影包验证）

| 设定 | 效果 |
|------|------|
| 时间线"中忍考试之前" | LLM 自然克制，不触发佩恩/四战 |
| 禁止"佐助提前叛逃" | 剧情方向受控 |
| characters 里的鸣人/佐助/卡卡西 | 出场时角色还原（一乐老板手打、菖蒲都正确） |
| hybrid 模式 | 细节（火影岩/味噌叉烧/中忍考试）由 LLM 记忆补全 |

## 注意事项

1. **IP 版权**：本平台用于个人创作/学习用途；商业发布需取得原作授权。
2. **原创新角色**：在 characters 里混合原创角色（如"xxx ｜ 木叶原创忍者"），LLM 会将其与原著角色区分。
3. **时间线变更**：若故事沿时间线推进，定期更新 world_facts 的 must_follow（如"中忍考试已结束"）。
4. **strict 模式**：若发现剧透/穿越，把 knowledge_mode 从 hybrid 调为 pack_only，并补充更多 must_follow。
