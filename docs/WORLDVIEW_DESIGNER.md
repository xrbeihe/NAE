# 世界观设计器指南

> 独立页面 `/designer`（从设置页「🎨 进入世界观设计器」进入），作者在浏览器内完成世界观创作全流程，无需写代码或 JSON。

## 入口

```
首页 → 🧑 头像菜单 → ⚙️ 用户设置 → 🌍 世界观设计器
或直接访问 http://<host>:8002/designer
```

## 功能总览

| 区块 | 功能 |
|------|------|
| ✨ 一键生成新世界观 | 填短表单生成完整世界观包 zip |
| 📋 世界观列表 | 每个世界观的 5 个操作按钮 + 校验/重载/删除 |
| 📦 上传安装 | zip 上传 + 自动校验 |

### 每个世界观的操作按钮

| 按钮 | 编辑内容 | 对应工件 |
|------|---------|---------|
| ✏️ 表单 | 角色创建表单结构（字段/控件/选项来源/自定义/提示小字/排序） | `form.json` |
| 💬 文案 | 按钮/标题/称呼 + 角色创建成功卡片（标题/内容行）+ 5 组初始推荐行动 | `ui.json` |
| 📋 选项 | 数据表格（职业/出身/性格/身份/特殊能力/地点/NPC身份池 + 9 个 NPC 生成池 tab：姓氏池/男名池/女名池/NPC性格池/修为级别池/体型池/衣着池/体质天赋池/NPC原型） | `player_templates.json` / `world_templates.json` / `npc_templates.json` |
| 📖 设定 | IP 世界观权威设定（知识模式/必须遵守/禁止出现/关键角色）+ 起始时间线编辑 | `world_facts.json` |
| 📤 开源 | 推送本世界观到开源共享库（填简介 + 点选标签），所有用户可在主页面「开源世界观广场」看到/评分/使用；作者可撤销 | 共享库表 |
| 校验 | 包完整性检查（缺文件/坏 JSON/语义） | — |
| 重载 | 清 loader 缓存（改文件后调用；重载某世界会后默认选中它） | — |
| 删除 | 删除包（默认包 xianxia_v1 受保护） | — |

> 📋 选项支持字符串数组（姓名池等，`kind: str_list`）与对象数组（NPC原型等）两种数据形态的增删改保存；NPC 原型的 identity/personality/cultivation/behavior_note 可可视化编辑，写回 `npc_templates.json` 的 `core_archetypes`。世界观特有的池（如海贼王的恶魔果实池/霸气池）也会按包内字段自动显示为 tab。
> 💬 文案编辑器的「角色创建成功卡片」可编辑标题与内容行（普通行/条件行、标签、数据键或模板、金手指尾注 tag_field）。
> 📖 设定编辑器的时间线区可创建/编辑/排序/删除起始时间线节点（id/标签/描述/必须遵守/禁止出现/关键角色）。

## 一键生成表单

分组输入，越详细生成的世界观越丰富：

### 基础信息
- 世界 ID（`^[a-z0-9_]{1,48}$`）、名称、一句话设定、风格基调（奇幻/现代/科幻/修仙）
- 能力体系名称、货币名称、对玩家称呼
- 职业列表、地点列表、创建按钮文案

### 🌏 世界设定（可选，丰富世界）
- 世界观详细设定（多行，成为 System Prompt 核心）
- 时代/纪元背景、主要势力、世界禁忌/规则

### 🧬 角色与内容（可选）
- NPC 姓氏池、特殊能力/金手指列表、事件主题

### IP 世界观选项
- `基于既有作品` 开关 + 作品名 → 生成 `world_facts.json` 骨架（见 [IP_WORLDVIEW.md](IP_WORLDVIEW.md)）

## 创作工作流

```
1. ✨ 一键生成 → 填表单 → 「生成并下载 zip」
2. 📦 上传安装 → 选 zip → 「上传安装」（自动校验）
3. 世界观列表 → 点校验确认无误
4. 按需用 ✏️ 表单 / 💬 文案 / 📋 选项 / 📖 设定 细化
5. 回首页 → 创建世界 → 选新世界观 → 开始
```

> 生成器自动拼接通用叙事内核（shell+kernel），作者无需写"叙事原则/输出格式"等通用 prompt。

## 常见操作

- **改文件后生效**：文件改动在服务器磁盘上，需点「重载」清 loader 缓存（生成器/编辑器保存会自动重载）
- **新包出现**：上传后列表即刷新；角色创建弹窗的世界观下拉每次打开都会重新拉取
- **重载后默认选中**：重载某世界会后，下次创建世界默认选它（写入 `ane_last_worldview`）
